# Air Quality Analysis Project

## Overview
This project analyzes air pollution data and applies machine learning models to predict AQI categories and cluster pollution patterns.

## Models Used
- KNN (k=3, k=5, k=7)
- Naive Bayes
- K-Means Clustering
- PCA for visualization

## Results
- KNN Best Accuracy: 64.07%
- Naive Bayes Accuracy: 99.45%
- K-Means: 3 pollution clusters
- PCA: 21.5% variance explained

## Tools
Python, Pandas, Scikit-learn, Matplotlib, Seaborn

## Conclusion
Naive Bayes performed best for classification, while K-Means helped identify hidden pollution patterns.
